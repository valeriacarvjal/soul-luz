# Souly Luz 🕯️

Website created for a handcrafted candle brand, focused on creating a premium, elegant and intuitive online experience.

## ✨ About the project

Souly Luz is a responsive website designed to showcase handmade candles and communicate the brand's identity through a warm and minimalist aesthetic.

The goal was to create a digital experience where users can explore products, discover candle benefits, learn how to care for their candles and easily contact the brand.

## 🚀 Features

- Responsive design for desktop, tablet and mobile
- Premium product showcase
- Individual candle sections
- WhatsApp integration for direct customer contact
- Product buttons with personalized WhatsApp messages
- Contact form connected with Formspree
- Candle care guide section
- Benefits and wellness section
- Smooth animations and elegant interactions

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Formspree
- Git & GitHub
